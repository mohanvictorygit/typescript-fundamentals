# TypeScript Fundamentals

This repository contains example files for learning TypeScript basics.

## Files

- `main.ts` — TypeScript source used as the example entry point.
- `main.js` — Compiled JavaScript (if present).
- `package.json` — Node package metadata.

## Requirements

- Node.js (v14+ recommended)
- npm or Yarn
- TypeScript compiler (`tsc`) for building the `.ts` sources

## Install

Install dependencies (if any) and the TypeScript compiler:

```bash
npm install
npm install --save-dev typescript
```

## Build & Run

Compile `main.ts` to JavaScript and run it:

```bash
npx tsc main.ts
node main.js
```

Alternatively, run TypeScript directly with `ts-node` (install it first):

```bash
npm install -g ts-node
ts-node main.ts
```
